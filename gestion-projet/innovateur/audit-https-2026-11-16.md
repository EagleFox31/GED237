# Audit de préparation HTTPS — lecture du code seule

- **Pour** : O (transmet à B), Q (rejeu du 20). Innovateur, 2026-11-16 ; lecture de `main` (origin/main) et de #109 (`ccdfd84`), **aucune exécution** : tout ce qui est marqué `Déduit` ou `À tester` reste à confirmer sur la pile (`curl`, navigateur) avant d'être tenu pour acquis.
- **Question** : qu'est-ce qui peut casser, ou se dégrader, sur `https://localhost:8443` derrière `nginx-tls` (#109) ? Réserve à lever : « une session survit-elle à F5 ? »

## Réponse courte

- **F5 en HTTPS : oui** (`Déduit`). Aucun cookie : jetons dans `sessionStorage` (`frontend/services/http/session.ts:70-72`, `frontend/stores/authStore.ts:147,177`), recharge de page dans le même onglet et la même origine = session conservée. Flags `Secure` et `SameSite` : sans objet.
- **Mais la session ne suit pas d'une origine à l'autre** : `sessionStorage` est propre à l'origine **et** à l'onglet. Basculer de `https://localhost:8443` vers `http://localhost:8080` (plan B du déroulé) demande une **nouvelle connexion avec OTP** dans chaque fenêtre. Écart n° 2 ci-dessous.
- Aucun écart bloquant pour les 8 parcours. Cinq écarts à corriger ou à tester avant le 19, dont un qui touche le déroulé (le nôtre).

## Points sans écart (vérifiés dans le code)

- **(a) Origines** : `ALLOWED_ORIGINS` (`docker-compose.yml:140`, surchargée par `docker-compose.tls.yml:10` avec `https://localhost:${TLS_PORT:-8443}`) ; `CORSMiddleware` (`backend/app/main.py:73-76`). Le front appelle `/api/v1` en relatif : même origine, le CORS n'est pas sollicité. Un poste ouvert par IP n'est pas dans la liste, sans conséquence pour la même raison. **`ALLOWED_HOSTS` n'existe pas** (aucun `TrustedHostMiddleware`).
- **(b) Cookies** : aucun `Set-Cookie`, aucun `SameSite`, `Secure` ni `HttpOnly` dans `backend/app` ni `frontend`. Rafraîchissement : `refresh_token` lu dans `sessionStorage` (`frontend/services/http/client.ts:40`).
- **(c) URL en dur** : seuls les repli de développement (`constants.tsx:4`, `Header.tsx:437`, `useNotifications.ts:37`) ; `nginx` : aucune URL absolue ; `VITE_API_URL=/api/v1` (`docker-compose.yml:219`, `frontend/Dockerfile:28`). Les URL `http://` de `frontend/e2e` et `playwright.config.ts` sont des tests (8080 inchangé).
- **(d) `root_path`** : aucun, nginx ne retire pas de préfixe : sans objet. `X-Forwarded-Proto` : transmis par `location /api/` (`app-locations.conf:12`), non exploité par l'API (écart 3). Limitation du débit par adresse : `TRUSTED_PROXY=true` (`docker-compose.yml:151`), `nginx-tls` pose lui aussi `X-Forwarded-For`.
- `nginx-tls.conf` : TLS 1.2 et 1.3, certificat monté en lecture seule hors dépôt, port hôte 8443 : conforme à `https-local.md`. HMR de Vite : `Upgrade` présent sur `location /` (`app-locations.conf:36-37`).
