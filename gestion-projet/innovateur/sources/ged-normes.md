# Normes GED / archivage et contexte Cameroun

Recherche web du 2026-11-09. Niveau : `Documenté` (sources listées), à recouper avant d'en faire un
critère d'acceptation.

## Normes internationales
- **ISO 15489** (records management) : principes de création, capture, classement, conservation,
  sort final ; métadonnées obligatoires ; traçabilité. Pertinent pour : plan de classement,
  journal d'audit, règles de conservation.
- **MoReq2010** : exigences modulaires pour systèmes de records (520 pages, lecture lourde) ; utile pour
  les modules classification, rétention, export/transfert.
- **ICA-Req (ISO 16175)** : exigences fonctionnelles pour records électroniques.
- Retour d'expérience sur l'application de ces normes :
  https://www.techniques-ingenieur.fr/base-documentaire/technologies-de-l-information-th9/gestion-de-contenus-numeriques-42311210/archivage-electronique-h7276/retour-d-experience-sur-l-application-des-normes-h7276v3niv10004.html
- Mémoire 2024–2026 appliquant ISO 15489 / ICA-Req / MoReq2010 (paramétrage, métadonnées, conservation) :
  https://thesis.dial.uclouvain.be/bitstreams/4f77c04f-cc50-4ad9-9b8e-c00fb7fbbc12/download

## Cameroun
- Groupe de travail interministériel e-gouvernement (avril 2025), coordination ministère de la
  Culture / Archives nationales : lignes directrices d'archivage numérique, base de données sécurisée,
  souveraineté des données :
  https://www.wearetech.africa/fr/fils/actualites/tech/e-gouvernance-le-cameroun-renforce-son-programme-de-numerisation-des-archives
  (repris par https://osiris.sn/e-gouvernance-le-cameroun-renforce-son-programme-de-numerisation-des-archives.html)
- Archives nationales et évaluation des acteurs e-gov :
  https://www.digitalbusiness.africa/cameroun-les-archives-nationales-donnent-le-la-a-levaluation-des-acteurs-de-le-gouvernment/
- Une trentaine d'administrations dans la transition vers l'archivage numérique (presse) :
  https://cameroon-tribune.cm/article.html/48952/fr.html/details_2
- Loi camerounaise sur les archives : définit le document électronique (support numérique lisible par
  machine) ; version en vigueur à vérifier (prc.cm).
- Travaux académiques locaux (ENSET, communes) : https://dicames.online/jspui/bitstream/20.500.12177/10131/1/ENSET_MEM_BC_22_0124.pdf

Aucune source ne montre une adoption formelle d'ISO 15489 ou MoReq2010 par le Cameroun ; aucune
actualité datée 2026 trouvée.

## Implications pour la présentation du 30/11 (Proposé)
- Mettre en avant : plan de classement par règles, journal d'audit, multi-tenant (une administration
  = un tenant), hébergement souverain possible (stockage local/MinIO), OCR plein texte.
- Vocabulaire à aligner sur ISO 15489 dans le support (capture, classement, conservation, sort final)
  sans prétendre à une conformité certifiée.
