# Textes d'aide des écrans V1.1 — proposition pour F

- **Pour** : F (infobulles et textes d'aide des PR #81, #84, #87, #88, #95), Q (vérifie le libellé affiché pendant la recette 20–23), O. Innovateur, 2026-11-10, non commité. Esprit `CLAUDE.md` « Copy utilisateur final » : court, plain français, pas de jargon interne (« référentiel », « manifeste », « OCR » seulement quand le mot est déjà à l'écran). Chaque écran : une **infobulle** (icône d'aide, une phrase) et, si besoin, un **texte d'aide** au clic (deux phrases au plus). Les chiffres cités sont ceux du code au 10/11 ; s'ils changent dans la PR, l'aide suit.

| Écran | Infobulle (icône d'aide, 1 phrase) | Texte d'aide au clic (2 phrases max) | Messages d'état à vérifier |
|---|---|---|---|
| **Tuile « Doublons refusés »** (tableau de bord, #81) | Fichiers refusés à l'import parce qu'un document identique existait déjà. | Le compte cumule tous les refus depuis la mise en service, dépôts et imports confondus (sous-texte « N dépôts · M imports »). Le détail de chaque refus se trouve dans le journal d'audit, action « Doublon refusé ». | Tuile à 0 : « Aucun doublon refusé ». |
| **Export / import des règles** (écran Règles, #84) | Exportez vos règles de classement dans un fichier pour les sauvegarder ou les charger ailleurs. | L'import reconnaît les règles déjà présentes : rien n'est créé en double, seules les règles modifiées sont mises à jour. Les règles actives le restent, les règles inactives aussi. | Après import : « N règles créées, M mises à jour, K inchangées ». Fichier illisible : « Ce fichier n'est pas un export de règles. » |
| **Export CSV du journal** (journal d'audit, #87) | Téléchargez les lignes affichées, avec les filtres en cours, au format CSV (Excel). | L'export s'arrête à 50 000 lignes. Au-delà, réduisez la période ou ajoutez un filtre avant de recommencer. | Dépassement : « Plus de 50 000 lignes : affinez la période ou les filtres. » Journal vide : bouton désactivé, « Rien à exporter ». |
| **Verrou du compte** (page de connexion, #88) | Après 3 codes erronés, le compte est bloqué 15 minutes. | Attendez la fin du compte à rebours avant de réessayer ; la saisie d'un nouveau code ne raccourcit pas le délai. Si vous ne pouvez pas attendre, demandez le déblocage à votre administrateur. | Message : « Compte verrouillé. Réessayez dans 14 min 59 s. » (compte à rebours vivant, bouton désactivé). Après déblocage : champ code réactivé sans message. |
| **Règles de contenu et d'année** (formulaire de règle, #95) | Classez un document d'après un mot ou une expression de son texte, et d'après son année. | Le texte n'est lu qu'une fois le document reconnu : un document déposé sans texte attend d'abord la reconnaissance, puis la règle s'applique s'il n'est pas déjà classé. L'année est lue dans le nom du fichier ; sans année dans le nom, la règle ne s'applique pas. | Simulateur : « Contenu non encore extrait » quand le document n'a pas de texte (message du moteur, repris tel quel). Année : l'écran affiche le détail du moteur ; sans année dans le nom du fichier : « Aucune année dans le nom du fichier » (après le correctif B). Champ année vide = pas de contrainte d'année. |

Deux règles transverses pour F :

1. **Une phrase par infobulle**, sans point d'exclamation ni verbe à l'infinitif en tête de phrase quand un impératif suffit (« Téléchargez », pas « Permet de télécharger »).
2. Les limites chiffrées (3 codes, 15 minutes, 50 000 lignes) apparaissent **dans l'aide, pas dans le libellé du bouton** ; le message d'erreur les répète au moment où l'utilisateur les rencontre.
